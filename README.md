# Test_Automation_Scripts
To evaluate the application's functionality, reliability, and user experience by validating critical grocery shopping workflows and identifying potential defects through Playwright automation testing.
Built a comprehensive end-to-end (E2E) test automation framework using Playwright and JavaScript (Page Object Model) for the GreenKart e-commerce web application.
Designed and automated risk-prioritized positive, negative, boundary, and exploratory test scenarios across six core modules—Product Search, Quantity Management, Shopping Cart, Promo Code Discounts, Checkout & Order Placement, and Offers Sorting—while documenting functional assumptions and identifying UI/edge-case defects.
